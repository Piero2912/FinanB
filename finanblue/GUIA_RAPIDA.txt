📌 COMENZAR EN 3 PASOS:

1. npm install
   Instala todas las dependencias necesarias

2. npm run dev
   Inicia el servidor de desarrollo en http://localhost:5173/

3. ¡Listo! 
   La app se abre con datos de ejemplo

💰 CARACTERÍSTICAS PRINCIPALES:

✓ Dashboard interactivo con gráficos
✓ Registra ingresos y gastos
✓ Presupuestos con alertas automáticas
✓ Metas de ahorro personalizables
✓ Estadísticas completas
✓ Responsivo: Desktop, Tablet, Mobile

🗂️ ESTRUCTURA:

src/components/       → Componentes React reutilizables
src/pages/           → Páginas principales (Dashboard, etc.)
src/context/         → Estado global (AppContext)
src/services/        → LocalStorage API
src/utils/           → Funciones auxiliares
src/types/           → Tipos TypeScript
src/data/            → Datos mock iniciales

🎯 FUNCIONALIDADES:

   - Crear ingreso/gasto
   - Editar
   - Eliminar
   - Buscar y filtrar

   - Ingresos vs Gastos (línea)
   - Gastos por categoría (donut)

💰 Presupuestos
   - Crear por categoría
   - Ver progreso
   - Alertas (50%, 75%, 90%, 100%)

🎯 Metas

   - Personalizar iconos y colores
   - Seguimiento visual
   - Alertas de plazo

❓ PREGUNTAS FRECUENTES:

P: ¿Dónde se guardan mis datos?
R: En LocalStorage del navegador. Solo tú los ves.

P: ¿Necesito crear cuenta?
R: No. Funciona sin registro.

P: ¿Funciona sin internet?
R: Sí, 100% offline.

P: ¿Es seguro?
R: Sí. Tus datos nunca salen del navegador.

P: ¿Puedo borrar datos?
R: Sí. Abre DevTools y limpia LocalStorage.
